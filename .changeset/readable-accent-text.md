Accessibility fixes. Text in the accent colour (eyebrow labels, tag names, the current menu item, links and inline code) uses a darker shade of the accent in light mode, so it stays readable against the light background. Bookmark, file and product cards follow the color scheme instead of staying white in dark mode, and their faded metadata is readable. The paywall's sign-in link keeps Ghost's colours. The player's speed button announces its visible value ("1× playback speed"), and code blocks and tables that scroll sideways can be focused with the keyboard.
